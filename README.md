# Flight Ticket Management System

A Python console application for managing flight-ticket data through a structured repository layer and menu-driven workflows.

## Highlights

- CSV-backed data storage
- Separation between input handling, menus and data-access logic
- Repository abstraction for working with application data
- Console-based user workflows

## Project structure

```text
main.py          # Application entry point
inputs.py        # Input parsing and validation
repository.py    # Data-access and domain operations
menus/           # CLI menus and workflows
csv_files/       # Project datasets
```

## Running

```bash
python3 main.py
```

## Tech stack

- Python
- CSV-based persistence
- Modular application structure

## Status

Academic Python project demonstrating structured application logic, file-based persistence and separation of responsibilities.
